# RF Workspace Pro - 24/7 Xiaozhi MCP Live Bridge

Cầu nối trực tiếp thời gian thực 24/7 giữa Robot AI Xiaozhi và 23 bảng CSDL Google Sheets của Rich Fish Aquarium.

## Deploy 24/7 miễn phí:
- **Render.com**: New Web Service -> chọn repo này -> Start Command: `node index.mjs`
- **Koyeb**: New Service -> GitHub -> chọn repo này
- **Docker**: `docker build -t rf-bridge . && docker run -p 3000:3000 rf-bridge`
